# 手机切换执行设备

iOS 0.7.3（36）与电脑、云端的手机连接插件 0.7.24 配套使用。点设备名，再选另一台设备，就是请求接管**当前会话**，不是复制任务。正在运行的工具先执行到可以核对结果的边界；若原任务在此之前正常完成，不再创建新的模型轮次。

## 工作区与源码

在原工作区用 `/source-share src tests` 登记允许两端同步的源码，也可以在专用工程中使用 `/source-share --project`。该授权不会从聊天文字、仓库内容或手机切换动作中推断。同步范围是保存到磁盘、符合共享规则的源码；不包括未保存的编辑器缓冲区、进程内存或任意附件。源码冲突、未登记目录、运行中的后台任务都不会被当成可直接接管的状态。

源端记录工具边界和源码版本，目标端核对版本、会话、权限及执行回执。云端为已登记的源码保留本地私有裸 Git 仓库：接管前生成恢复点，后台也会检查变更（约 30 秒一次）。它不会改工程的分支，不会推送到 GitHub。源码共享的授权仍需慎重：请勿在普通源码文件中硬编码密钥。

## 执行与回执

手机等待目标 DSH 接受原任务后才切换。重复选择或重新打开手机端会复用同一笔未确认请求。目标 agent 在首次模型请求中读取环境变更和进度；`relay_environment` 还可查看可用 shell、工作目录、源码状态和部署观察记录。工具返回成功并不等于部署成功；需要用原部署编号或目标系统状态核实。无法核实的操作不能仅凭没看到输出就再发一次。

云端已持久收到交接和所需源码后不依赖原 DSH 在线。若断电发生在交接或源码送达之前，不能把最近一次历史截图当成新的执行权。另一个原生会话写入器仍占用目标时也不强行覆盖；手机保留原连接并报告交接未确认。此功能不是操作系统进程迁移。
