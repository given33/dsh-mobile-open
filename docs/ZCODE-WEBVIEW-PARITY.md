# ZCode Web 远控对照

对照基线：`zai-org/ZCode` `fec975905a2abd4c07e35c40d51fa097a2258ec9`（3.18.2）。上游源码中 Web 远控在 `packages/web/src/web-remote-control/`，Android 承载壳在 `packages/android/`，会话组件在 `packages/ui/`。

| 能力 | DSH Mobile 状态 |
| --- | --- |
| 前后台、冻结恢复、网络恢复事件合并 | 移植上游 lifecycle 模块。初次 `pageshow` 不重连；隐藏期间不探测；真实恢复只发起一次校验，仍用 DSH 的连接与证书验证。 |
| 会话阅读位置 | 移植上游有容量限制的内存缓存。同一页面切换会话时还原位置，滑到底之后重新进入则贴新底。冷启动不读这份内存，仍恢复退出前的会话并显示最新记录。 |
| 任务导航、窄屏/宽屏 | 保留 DSH 工作区与会话入口；补充工具箱中的待确认、运行中、历史分组、全列表搜索（标题和工作区名）、渐进显示。底部弹层使用浏览器原生模态层，隔离背景并尊重系统「减少动态效果」。 |
| 配对，掉线后保留会话与输入草稿，旧快照先绘制 | 使用现有 DSH 本地配对及连接；未引入上游账号、relay 或第三方数据传输。 |
| 上游快照字节预算、按字段补拉正文 | 尚未移植。DSH 宿主须先提供可分页的会话历史和稳定正文引用；目前只复用宿主已有的历史读取和压缩，不能在插件中擅自裁剪会话。 |
| ZCode 账号、云中继、多实例窗口 bridge、任务已读同步 | 非源码替换项。与 ZCode 的设备/会话域和 host 协议绑定；没有映射到 DSH 的字段不伪造、不增加权限。 |

直接复用的源码、来源与许可见 [第三方声明](../desktop/THIRD_PARTY_NOTICES.md#zai-zcode)。
