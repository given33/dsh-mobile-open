DSH 手机连接 0.7.15 ｜ 安装与配对

电脑（Windows · DeepSeek Harness 桌面版）
1. 先打开一次 DSH 以初始化配置。保存当前工作，从托盘完全退出 DSH。解压整个 ZIP，再双击 Install.cmd。无需管理员权限、私有仓库或单独安装开发工具。脚本调用 DSH 自带的插件管理器，不改系统执行策略。
2. 看到安装成功后，重新打开 DSH；在左下角点「手机连接」，启用连接并显示二维码。旧版使用同一个插件名；升级无需手动清空配对或聊天。
3. 若使用自定义安装目录，运行 Install-DSHPhone.ps1 -DshCli "你的绝对路径\dsh.cmd"。安装包会留存在 DSH 用户配置目录的 mobile-link-packages 文件夹，完成后可删除解压目录。
4. 不使用 Windows 安装助手时，把同目录下 .tgz 保存在固定位置，运行 dsh plugin --profile desktop add "压缩包的绝对路径"。只有使用 dsh web 才改用 --profile web。已验证 Windows 桌面 CLI；其它系统未做安装器实测。

手机
• 输入栏优先显示模型名，推理强度可在模型选择菜单中查看或调整。支持原生听写的客户端中，麦克风固定在发送键左边。
• 手机与电脑先连接同一可信 Wi-Fi。在手机里点「扫描电脑上的二维码」（或粘贴配对链接），核对两端显示的安全码后确认。已配对后，每次打开和回到前台都会静默恢复，无须再确认。不要把自己的配对二维码或链接发给别人。
• 希望手机发消息或创建工作区会话，需要在电脑开启「允许手机操作」。终端权限独立，默认不需要打开。
• 公网/蜂窝访问需要能到达这台电脑的入口（例如已配置的 TCP 中继或私网）；安装插件不会自动开放公网，电脑和 DSH 必须保持运行。
• DOCX/DOC/PPTX/XLSX/ODT/ODP/ODS/CSV/TSV 默认由桌面极速解析为「原文阅读」，自动修复中文编码与数学符号乱码，无需在手机下载整份大文件；需要图片与原始排版时，可在文件工具栏一键切换原版式，或点 ↓ 保存原件。

隐私与卸载
• 该包不附带任何人的配对凭证、账户或公网中继。可随时在电脑「手机连接」关闭连接、撤销某台设备，或在 DSH 插件管理中停用/移除 dsh-mobile-link。

配对了云端并启用 cloudTurns 后，电脑端在原会话打开「手机连接 → 本会话云端执行」提交新的云端任务。请在云端看到本轮开始后再给电脑断电。电脑登录后的后台收件不依赖桌面 DSH；管理员配置与边界见仓库 deploy/cloud/README.md。
